# Changelog

All notable changes are listed here, newest first. Format: Keep a Changelog; versions follow SemVer.

## [0.1.0] - 2026-11-04

### Added

- Dependencies in the whole environment: the details of a reference have Check dependencies, which lists everything that uses it in any solution (flows, agents, apps, other components) with state, owner and the solutions that hold them, marking what is outside the open solution. The same in the new-reference panel (every reference that holds a connection and the total for the connection) and in Clean up (a verdict per unused reference, Select the ones nobody uses, and the duplicates). A blocked Delete now names the components that block it. Read only, on request, from Dataverse dependency tracking.
- A confirmation over the clean up dialog no longer flashes on every click.
- Clean up: Remove and Delete now open their confirmation over the clean up dialog instead of taking you to the list; Cancel returns to it with your ticks, and after the Result it opens again with the list read anew.
- While an action is running (a check, a read, a write, a creation) every button is disabled, by one rule for the whole tool; the control that is working keeps its look and shows its spinner. The list of Clean up keeps its scroll position when you click in it.
- Clean up: Check dependencies works on the ticked references (all when none is ticked), the buttons sit on one line, the wait shows its progress in the button, and the summary is one line that can be closed.
- The Clean up list scrolls: it was cut at the bottom of the dialog when there were many references.
- Clean up: a dialog in the Connection references view lists the references nobody uses (with their connector, connection and tags such as Never connected or Duplicate of) and the groups of duplicates (same connector, same connection). Tick the unused ones to remove them from the solution or delete them through the usual dialogs. Merge a group of duplicates: choose the reference to keep, re-point the flows of the others to it (Preview and confirmation as always), then the Result offers the duplicates, now unused, for removal with their own preview. Managed references cannot be ticked, flows that could not be read are reported, and nothing is written by the dialog itself.
- The fields of the new-reference panel take the full width of the panel.
- Creating a reference now shows what is happening: the three steps (checked again, created and added, read back) light up as they are reached, the button has a spinner, a thin bar runs while it works, and "Created" is shown for a moment before the panel closes.
- A pasted connection id is now looked up only when you press Enter or the search icon (not while typing), and pressing the icon no longer throws the panel back to the top.
- The new-reference panel is wider and its header lower; clicking a connection, "Used by" or a suggestion no longer throws the panel back to the top; an applied suggestion is marked and the suggestions fold into one line.
- A reference created from the panel can now be removed or deleted straight away; before, it was refused until the solution was refreshed.
- A pasted connection id in the new-reference panel must exist: the tool lists the connections of the environment (Power Platform API), offers them as cards with who uses them, checks a pasted id (Check, Enter, or a whole resource id), refuses a missing one or one of another connector, and checks again just before writing. Without access to the list only "No connection yet" is possible. Suggestions fill the display name, name and description in the Maker style, a readable style, or by account.
- New connection reference from the re-point dialog: in a category, "New reference" opens a side panel that slides in from the right (Details, then Review) with the connector fixed to that category, a display name, a name with the publisher prefix in front (suggested from the display name), a description and an optional connection (none, one already in use, or pasted). Review shows the exact record; Create adds one row to the solution, reads it back, selects it as the reference to use instead, and deletes it again if it cannot be completed.
- Remove from solution and Delete: two new actions in the bar over the table in the Connection references view. Remove takes the selection out of the open unmanaged solution and leaves the rows in the environment; Delete removes the rows from the environment. Both go through the same preview, confirmation and per-row result; each row is checked just before and read back after. A reference still used by a flow is blocked, and Delete asks for its own acknowledgement and offers a copy of the records first.
- The choices of a change are made in a studio dialog that can fill the window; the choose screen keeps only a slim selection bar of fixed width with one button, so the table keeps its room and nothing jumps.
- A shorter path: Review changes opens the exact Preview at once (Choose, Preview, Apply, Result); the separate Review step, which repeated the same list, is gone, and the Preview says why when no row can be written.
- With your permission (off by default) the tool turns flows that are on off for the change and on again afterwards: a block in the studio, a warning that lists what it means and the flows, a second acknowledgement, a run with six phases, every flow turned off is turned on again even when its write fails, a flow left off is named in the result and in the report.
- The studio of a re-point goes through the connectors one at a time: a pipeline on top (a step per connector, then a summary), Next and Back, a slide between steps, with Back and Next in the bottom bar and the figures always underneath.
- Re-point by category: the references to replace are grouped by connector, each category with its own colour, share bar and percentages; tick one, some or all per category, choose a new reference for each, and every category is changed in one operation, one write per flow.
- A flow that already uses the new reference (chosen among the ones to replace) is shown as "Already uses the new reference: nothing to change", not as an error.
- Re-point several references to one in a single operation: tick every reference to replace (one connector), choose the one to use instead (it may be one of them), and each flow holding any of them is rewritten once.
- See which connection references each flow of a solution uses, and group by reference.
- Flags for references with no connection and for flows that declare a missing reference.
- Bulk change of the connection of references, and bulk re-point of flows to another reference, each with a preview and a result per row.
- Each connection reference of a flow is shown as a block with a connector glyph, then the official connector name, the reference name, its logical name and the connection in full, one under the other; custom connectors are marked; the attention column appears only when something needs attention.
- Flows show their type (instant, automated, scheduled), and every flow and connection reference opens a details panel with key-value pairs and a table of its connections or of the flows that use it; the layout uses the full width and adapts to narrow panes; the view keeps its scroll position.
- Icons everywhere they help: a glyph for each flow type (instant, automated, scheduled), state, connection and warning chip, every detail label and block title, buttons and empty states; connector tiles are tinted by kind of service.
- A change now runs as Choose, Review, Preview, Apply and Result with a stepper and a breadcrumb; the Preview shows exactly what will be stored as a line diff (split or unified) or a table; the Apply step shows a timeline with the elapsed time and each row as it finishes; the Result states what happened in a banner, figures and rows, and can save a report.
- Re-pointing offers only compatible choices: the new reference is disabled until a reference to replace is chosen and lists only other references of the same connector in the solution; a connection choice is disabled for references of different connectors.
- Every write is confirmed in a dialog over the screen with the environment, figures, before-and-after rows, warnings, backup and an acknowledgement; Apply stays disabled until it is ticked.
- Bulk actions sit in one framed block with labelled fields and a count that never changes width; connections are chosen from a list or pasted, with no browser suggestion pop-up.
- Typing in a field keeps the cursor.
- Home screen with the environment name in the header, the number of solutions and flows, a sortable solution table with the flows of each solution, search with a clear button and an Updating indicator.
- Managed solutions are not offered (a disabled Managed tab shows their count).
- Save a backup of the old values from the preview.
- Safety checks: rows changed by someone else since the preview are skipped, every write is read back, mixed connectors are blocked, and the preview warns about flows turned on and references owned by someone else.
